https://www.ars.usda.gov/ARSUserFiles/21904/BrennanPeerRevPdfs/Agron%20J%20104p684.pdf, extracted per the script header
into a scratch folder outside the repo (cd "$(mktemp -d)" && mutool extract paper.pdf). That copy holds the figure as a
500 x 792 Flate PNG, not the 667 x 1056 publisher JPEG the script is calibrated on, so it was upscaled with
ImageMagick (convert image-0024.png -resize 667x1056! fig5_667x1056.jpg). The figure itself is not in evidence.
