Data reference

This page describes the committed CSV exports and their use. The collection protocol separately describes curation principles and draft schema proposals. The schema in datapackage.json, together with source-specific provenance, governs the exported site tables.

Datasets

Sources include replicate-level archives and provider-reported annual flux products; companion analysis papers supply methods and cross-checks. A dataset is curated in its own workbook, and ingest stacks each tab across all workbooks into one CSV per table.

white_salinas_2020

Organic vegetable rotation (romaine lettuce, broccoli) with winter cover crops and compost. Randomized complete block, 4 blocks, so block level is replicate level here. Companion analysis paper focuses on 5 systems (those with optimal cover crop seeding rates); workbook carries all 8 from archive. SOC stock is concentration times bulk density times depth (0 to 30 cm), with bulk density measured only at end of Years 3 and 7 and propagated by equivalent soil mass, so core_sample method row carries that propagation rule. A large Year 0 to Year 1 SOC drop appears across all systems including no compost control, and is documented in source.

nichols_modesto_2024

Long term compost orchard with high frequency low concentration drip fertigation (about 195 kg N ha-1 across 14 events). N2O measured by closed static chamber on 9 dates (Dec 2018 to Aug 2019), 3 replicate arrays per treatment, upscaled to emitter level. Soil total C, total N, and bulk density are single timepoint (August 2019), so this dataset supports N2O magnitude and contrast validation but not a SOC trajectory.

The table above predates the AmeriFlux Delta and Bouldin chamber datasets. As of those, N2O is covered at three sites (nichols_modesto_2024 static chamber; anthony_bouldin_2024 automated chamber at US-Bi2 and US-Bi1) and CH4 at three (tower annual budgets for US-Twt, US-Bi1 and US-Bi2, plus chamber CH4 at the two Bouldin sites). Conventions

  • Stable text keys. A site key is physical location only; it does not encode treatment, replicate, or date. Treatment keys (socs_sys1, compost, no_compost) stay stable across a dataset.
  • Long format, replicate level. Where a paper has a companion data archive, ingest replicate level values from archive; summary tables in analysis paper are for cross checking, not primary fill source.
  • Dates. Record source stated range in min_date and max_date. An exact date sets both equal; a stated month or season bounds interval; an unknown date stays blank with reason in notes. Never invent a day of year.
  • Statistics. Store reported statistic (n, statname, stat) as given. Statistic conversion (standard deviation to standard error, and similar) is a downstream step, not curation.
  • Basis. Methods state dry vs wet basis (prefer dry) and volumetric vs mass basis. Amendment rates carry their basis in units.
  • fill_status. Provenance code for each value. Codes in current data: FILLED_SITE_DATA_XLSX, FILLED_ZOTERO_XLSX, FILLED_DATASET. Additional codes (PAPER_TEXT, NEEDS_FILL, MISSING_IN_SOURCE) are reserved for rows still being curated.

Validation

scripts/validate.R checks every generated data/*.csv against datapackage.json. It runs in warn mode: missing columns, empty keys, broken foreign keys, and odd dates warn but do not stop, so a workbook in progress can exit successfully with unresolved problems. Review every warning; the stricter tests and CI checks are separate gates. It needs only base R plus jsonlite and readr.

Rscript scripts/validate.R

Tests under tests/testthat/ run the same checks via testthat. The committed snapshot supplies the tables tested here. Tests can skip absent tables; review skips and warnings as well as failures.

Rscript -e 'testthat::test_dir("tests/testthat")'

Usage

Load a table

library(readr)
obs <- read_csv("data/observations.csv", show_col_types = FALSE,
                col_types = cols(.default = col_character()))

# replicate level SOC stock
subset(obs, variable == "SOC_stock_Mg_ha" & observation_level == "replicate")

Pull a treatment contrast

pairs <- read_csv("data/treatment_pairs.csv", show_col_types = FALSE)

# contrasts flagged for validation (e.g. compost vs no compost)
subset(pairs, use_for_validation == TRUE)

Regenerate the snapshot from the workbook

# set workbook id in 000-config.yml first, then authenticate once
# interactively with googlesheets4::gs4_auth()
source("scripts/ingest.R")

Synthesis data products

Synthesis worksheets are exported separately from the site tables. The synthesis README documents sources, subclasses, uncertainty, and selection decisions.

File Purpose
extracted_evidence.csv Source findings with citations and locators
normalised_targets.csv Derived target quantities and explicit uncertainty definitions
summarized_targets.csv Selected rows keyed by practice, outcome, and subclass
reference_values.csv Contextual values; the selected Mediterranean EF level also appears here and must not be counted twice
model_vs_evidence.csv Evidence-side comparison scaffold; empty model columns do not represent model results
coverage.csv, evidence_assessment.csv, source_audit.csv Coverage, conditional assessments, and source review
carb_crosscheck.csv, data_processing.csv, data_ingest_report.md Inventory cross-checks, digitization records, and transformation notes

The six likelihood-eligible practice–outcome groups are not six independent scalar observations. Fertilizer N2O has an EF level and alternative crop-specific slopes; rice CH4 has overlapping drying-event subclasses. Match the observation operator and select applicable subgroups rather than counting overlapping estimates as independent evidence.

To compare synthesis exports against the workbook without rewriting them:

Rscript scripts/ingest_benchmarking.R --check

This requires authorized Google Sheets access, googlesheets4 and readr. Set CCMMF_SHEETS_EMAIL to the authorized account before running the synthesis script; without it, the script uses its configured default account. The script without --check rewrites exports. Site ingestion also requires config and dplyr. Ingestion does not replace source review or validate scientific comparability.

Build and maintain the documentation

The homepage includes the root README, so edit the README to update both entry points. Detailed dataset and schema information belongs on this page; report interpretations belong in Parts A–C. Update source-check dates when reconciling adaptations with the linked Google Docs.

python3 -m unittest discover -s tests -p 'test_documentation.py'
python3 scripts/build_evidence_figures.py --check
quarto render
python3 scripts/check_site.py
quarto preview

The figure check compares versioned evidence diagrams with the committed synthesis targets. Run it without --check to regenerate those diagrams after a reviewed target update. The site check verifies rendered local links and figure alt text. Neither command ingests workbooks, runs a model, or publishes a site.
